## 1. HTML-in-Canvas API(Chrome 157 で安定版)

参考: https://developer.chrome.com/blog/html-in-canvas

- ①目的: ライブで操作可能・アクセシブルな DOM サブツリーを 2D / WebGL / WebGPU の canvas に描画する。従来は canvas 内のテキストやUIを自前で再実装する必要があった。
- ②ライブラリ対応: Three.js(実験的 `THREE.HTMLTexture`)、Babylon.js(`BABYLON.HtmlTexture`)、PixiJS v8.19.0(`HTMLSource`)。
- 注意: Chrome 150/155 で API が変更され、PixiJS の `HTMLSource` は Chrome 157 で `texElementImage2D is not available` となる報告がある(PixiJS PR #12341)。`content="drawable"` が必要になる。
- ③効果の理由・具体コード: 取得できず未記載。
