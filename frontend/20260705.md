## 1. Meta's Astryx: オープンソースの React デザインシステム

**URL**: https://github.com/facebook/astryx  
**ドキュメント**: https://astryx.atmeta.com/

### ①目的・問題意識

Meta が 8 年かけて社内で育ててきたデザインシステムを MIT ライセンスで公開したもの。社内では 13,000 以上のアプリを動かしており、人間のエンジニアと AI コーディングエージェント（Claude Code, Cursor, GitHub Copilot など）が同じ CLI・MCP コマンドで使えることを設計の中心に据えた最初のメジャーなデザインシステム。

従来のデザインシステムは人間が読むドキュメント前提だったが、Astryx は AI エージェントも同じ API で操作できるよう MCP サーバーを同梱する。

### ②技術詳細・コード例

#### パッケージ構成

| パッケージ | 役割 |
|---|---|
| `@astryxdesign/core` | コンポーネント・テーマシステム・ユーティリティ |
| `@astryxdesign/cli` | スキャフォールディング、コードモッド、テンプレート生成 |
| `@astryxdesign/build` | StyleX ビルドプラグイン |
| `@astryxdesign/theme-*` | 10 種類のカスタマイズ可能テーマ |

#### インストール

```bash
npm install @astryxdesign/core @astryxdesign/theme-neutral
npm install -D @astryxdesign/cli
```

#### セットアップ（Next.js）

```tsx
// app/providers.tsx
import { Theme } from '@astryxdesign/core/theme';
import { LinkProvider } from '@astryxdesign/core/Link';
import { neutralTheme } from '@astryxdesign/theme-neutral/built';
import Link from 'next/link';

export function Providers({ children }: { children: React.ReactNode }) {
  return (
    <Theme theme={neutralTheme}>
      <LinkProvider component={Link}>{children}</LinkProvider>
    </Theme>
  );
}
```

CSS インポートはビルドプラグイン不要で、3 ファイルを順に import するだけ:

```css
/* app/globals.css */
@import '@astryxdesign/core/reset.css';
@import '@astryxdesign/core/components.css';
@import '@astryxdesign/theme-neutral/theme.css';
```

#### Tailwind との併用

Astryx トークンを Tailwind ユーティリティにブリッジする CSS を追加するだけで共存できる:

```css
@import '@astryxdesign/theme-neutral/tailwind-theme.css';
/* bg-surface → --color-background-surface にマップされる */
```

#### CLI コマンド

```bash
# コンポーネントのドキュメントとテンプレートを取得
npx astryx component Button

# 利用可能なページテンプレート一覧
npx astryx template --list

# テーマガイドを確認
npx astryx docs theme

# MCP サーバー用マニフェスト（JSON 形式）
npx astryx manifest --json
```

#### MCP サーバーの仕組み

`astryx manifest --json` が返す JSON はすべてのコマンド・引数・フラグ・レスポンス型を機械可読な形で記述する。AI エージェントはこの manifest を読むことで、Astryx の全機能を人間と同じように操作できる。

```json
{
  "commands": [
    {
      "name": "component",
      "args": [{ "name": "name", "type": "string", "required": true }],
      "description": "Returns full documentation and templates for a component"
    }
  ]
}
```

#### テーマシステム

10 種類のテーマが同梱される: `default`, `neutral`, `daily`, `butter`, `chocolate`, `matcha`, `stone`, `gothic`, `brutalist`, `y2k`

テーマは CSS カスタムプロパティのトークンで表現されており、トークン値を差し替えるだけでシステム全体が自動でリスタイルされる（コンポーネントコードの変更不要）:

```css
/* theme-neutral/theme.css の一部 */
:root {
  --color-background-surface: #f5f5f5;
  --color-foreground-primary: #1a1a1a;
  --border-radius-medium: 6px;
}
```

#### StyleX 統合

内部は Meta が開発したコンパイル時 CSS エンジン StyleX で構築されており、ランタイムでスタイルを注入せずビルド時にアトミック CSS を生成する。外部からは Tailwind・CSS Modules・プレーン CSS も使える（`className` override 対応）。

### ③なぜ効果的か

- **ビルドプラグイン不要**: CSS インポートのみで動作するため既存スタックへの導入コストが低い
- **オープンインターナル**: コンポーネントのどの階層でも合成・拡張でき、ソースコードごと eject（swizzle）することも可能
- **AI-ready**: MCP サーバーと CLI を人間と同じ API で設計することで、エージェントと人間が同一の設計ガイドラインに従う。コンポーネントの JSDoc に合成ヒントが書かれており、エージェントが誤った使い方をしにくい
- **パフォーマンス**: StyleX によるアトミック CSS でバンドルサイズが膨らまない

## 2. mapcn — shadcn/ui スタイルの React マップコンポーネント

**URL**: https://www.mapcn.dev/docs  
**GitHub**: https://github.com/AnmolSaini16/mapcn

### ①目的・問題意識

Mapbox などの地図 SDK は設定が複雑で API キーのベンダーロックインが伴い、商用ライセンス費用も課題になる。mapcn は shadcn/ui と同じ「コピーペーストで自分のコードにする」アプローチで、MapLibre GL（完全オープンソース・API キー不要）と Tailwind CSS を組み合わせた地図コンポーネントをゼロ設定・ワンコマンドで使えるようにしたライブラリ。

### ②技術詳細・コード例

#### 技術スタック

| 技術 | 役割 |
|---|---|
| MapLibre GL | 地図レンダリングエンジン（Mapbox の OSS フォーク） |
| Tailwind CSS | スタイリング |
| shadcn/ui | コンポーネントパターン（copy-paste 方式） |
| TypeScript | 主要言語（98.3%） |

#### インストール（shadcn/ui プロジェクトに追加）

```bash
npx shadcn@latest add https://mapcn.dev/maps/map.json
```

これだけで MapLibre GL のセットアップ・コンポーネントファイルの生成まで完了する。

#### 基本的な使い方

```tsx
import { BasicMap } from '@/components/maps/basic-map';

export default function Page() {
  return (
    <BasicMap
      center={[139.6917, 35.6895]}  // 経度, 緯度
      zoom={12}
      style="https://demotiles.maplibre.org/style.json"
      className="w-full h-[500px]"
    />
  );
}
```

#### マーカーとポップアップ

```tsx
import { BasicMap, Marker, Popup } from '@/components/maps/basic-map';

export default function Page() {
  return (
    <BasicMap center={[139.6917, 35.6895]} zoom={12}>
      <Marker longitude={139.6917} latitude={35.6895}>
        <Popup>
          <p>東京都庁</p>
        </Popup>
      </Marker>
    </BasicMap>
  );
}
```

#### 主な機能

- ライト/ダークモード対応（テーマ連動）
- ゼロコンフィグ・デフォルト値あり
- マーカー・ポップアップ
- ルート描画
- コントロール（ズーム、コンパス、現在地、フルスクリーン）
- React Native 版（`mapcn-rn`）も提供

#### shadcn/ui との関係

shadcn/ui と同じく「ライブラリとして依存しない」モデルを採用。`npx shadcn add` でコンポーネントのソースコードをプロジェクトに直接生成するため、独自カスタマイズが自由にできてバージョンロックインがない。

### ③なぜ効果的か

- **MapLibre GL** を基盤にすることで Mapbox API キーもライセンス費用も不要
- shadcn/ui ユーザーはすでに馴染みのある `npx shadcn add` のワークフローで導入できる
- Tailwind の utility クラスでスタイリングするため、デザインシステムとの統一が容易
- 10,000+ GitHub スター・MIT ライセンスのコミュニティプロジェクト

### nuqs 2.9 — React Router v8 対応の URL ステート管理

**GitHub**: https://github.com/47ng/nuqs

React フレームワーク向けの型安全な URL クエリパラメータ管理ライブラリ。`useState` の代わりに URL のクエリ文字列にステートを保存する。2.9.0（2026年6月30日リリース）で React Router v8 サポートが追加。

```tsx
// React Router v8 でのセットアップ
import { NuqsAdapter } from 'nuqs/adapters/react-router/v8';
import { Outlet } from 'react-router';

export default function App() {
  return (
    <NuqsAdapter>
      <Outlet />
    </NuqsAdapter>
  );
}
```

```tsx
// 使い方（useState の代わり）
import { useQueryState } from 'nuqs';

function SearchComponent() {
  const [query, setQuery] = useQueryState('q');
  // URL: /search?q=react
  return <input value={query ?? ''} onChange={e => setQuery(e.target.value)} />;
}
```

**ポイント**: v8 と v7 は同じ hooks を expose しているため、v8 アダプターは現在 v7 アダプターを re-export する実装。将来の実装分岐に備えて `nuqs/adapters/react-router/v8` を import しておく。

### Takumi — Rust 製の JSX→画像レンダリングエンジン

**URL**: https://takumi.kane.tw/  
**GitHub**: https://github.com/kane50613/takumi

#### 目的

OG 画像生成などで使われる Satori の代替。Headless Chromium を不要にし、単一の Rust バイナリで JSX・HTML・CSS を PNG/JPEG/WebP/SVG/GIF などに変換する。Chromium は起動に約 300MB のメモリと cold-start コストが必要だが、Takumi は関数呼び出し 1 つで完結する。

#### コード例

```bash
bun i takumi-js
```

```tsx
import { render } from 'takumi-js';

const image = await render(
  <div tw="w-full h-full flex items-center justify-center bg-white">
    <h1 tw="text-6xl font-bold text-gray-900">Hello from Takumi</h1>
  </div>,
  { width: 1200, height: 630 }
);
// image は Uint8Array (PNG)
```

#### アーキテクチャ

レンダリングパイプライン:
1. **レイアウト**: Taffy（Flexbox・Grid・positioning 対応）
2. **テキストシェーピング**: WOFF/WOFF2 フォント・絵文字・RTL サポート
3. **合成**: スタッキング・ブレンドモード・フィルター・トランスフォーム
4. **エンコード**: PNG/JPEG/WebP/SVG/GIF/APNG 出力

#### 対応環境

- **Node.js**: ネイティブバインディング
- **Cloudflare Workers / ブラウザ**: WASM ビルド
- **Rust アプリ**: クレートとして埋め込み

Satori 比で 2〜10x の高速化をベンチマーク上で達成。Babel プラグインとして使う場合は TypeScript 版 React Compiler と比べ約 3x 高速。
