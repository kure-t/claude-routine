### 2. WebKit Features for Safari 27.0
- URL: https://webkit.org/blog/18325/webkit-features-for-safari-27-0/
- 本文は未取得。二次情報（検索要約）で確認できた点:
  - **Safari MCP server**: コーディングエージェント（Claude Code, Codex 等）が DOM・ネットワークリクエスト・スクリーンショット・コンソール出力を検査可能。有効化は Safari > Settings > Developer の「Allow remote automation and external agents」にチェック。
  - **Customizable Select**: `select` と `::picker(select)` の両方に `appearance: base-select` を適用して完全にスタイル可能なドロップダウンを作る。
    ```css
    select,
    select::picker(select) {
      appearance: base-select;
    }
    ```
    （上記は要約にある機構の最小例。公式記事のコード全文ではない。）
  - **ES モジュールローダーの C++ 書き換え**: top-level `await` の順序バグを修正し、仕様準拠を実現。
  - その他: SVG の多数の修正、anchor positioning の改善、WebAssembly JSPI 対応。ベータから機能数が 58→83 に増加（情報源により修正数の表記が異なる）。
