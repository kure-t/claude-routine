## 1. 伝わるテキストデザインのための5つのCSSプロパティ

**記事タイトル**: 5 CSS Properties You Should Know for Better Text Designs
**掲載元**: Master.dev Blog
**URL**: [https://master.dev/blog/typographic-css-tricks/](https://master.dev/blog/typographic-css-tricks/)（Frontend Focus #754 の目玉記事として言及）

### ① 目的・問題意識

Web タイポグラフィにおいて、`font-family` や `font-size` といった基本プロパティだけでは表現力に限界がある。この記事は、あまり知られていない・見落とされがちな CSS プロパティを使って、テキストに視覚的なインパクトを与える方法を紹介するもの。取り上げられているのは以下の5つ。

1. `letter-spacing`
2. `background-clip: text`
3. `box-decoration-break`
4. `text-combine-upright`
5. `align-content`（テキストの垂直配置における新しい選択肢として）

### ② 具体的な技術詳細とコード例

#### 1. `letter-spacing` — 文字間隔を使ったテキストリビール演出

`letter-spacing` は各グリフの後方に挿入される空白量を制御するプロパティで、正の値・負の値の両方を取れる。単なる字間調整だけでなく、**アニメーションさせることでテキストが引き伸ばされながら現れる「テキストリビール」演出**に応用できる点が過小評価されている、というのが記事の主張。

```css
.reveal-text {
  letter-spacing: 0.5em;
  opacity: 0;
  animation: reveal 1s ease-out forwards;
}

@keyframes reveal {
  to {
    letter-spacing: normal;
    opacity: 1;
  }
}
```

**なぜ効果的か**: 大きな `letter-spacing` から `normal` へアニメーションさせることで、文字が「引き寄せられて」フォーカスが定まるような視覚効果が生まれる。JavaScript 不要でパフォーマンスの良い演出ができる。

#### 2. `background-clip: text` — 背景をテキストの形にマスクする

2000年代後半から存在する古典的テクニックだが、いまだにタイポグラフィ表現で最も人気のある手法の一つ。`background-clip` に `text` 値を指定すると、要素の背景（画像やグラデーション）を前景のテキスト形状でクリッピング（マスク）できる。文字色を透明にすることで、背景がテキストの中だけに見える状態を作る。

```css
.gradient-text {
  background-image: linear-gradient(90deg, #ff6b6b, #4ecdc4, #45b7d1);
  background-clip: text;
  -webkit-background-clip: text;
  color: transparent;
  -webkit-text-fill-color: transparent;
}
```

**なぜ効果的か**: グラデーションや画像テクスチャをテキストに直接適用でき、画像化せずに検索可能・選択可能なテキストのまま鮮やかな見た目を実現できる。

#### 3. `box-decoration-break` — 折り返した行・カラム・ページごとの装飾制御

インライン要素（テキストなど）が複数行・複数カラム・複数ページにまたがって「フラグメント（断片）化」された際に、境界線・パディング・マージン・背景・box-shadow・border-radius をどう描画するかを制御するプロパティ。

- **`slice`（初期値）**: 要素全体をフラグメント化されていない1つの箱として描画したのち、行/カラム/ページ単位で「スライス」する。装飾は連続した1つの箱であるかのように見える。
- **`clone`**: フラグメントごとに境界線・パディング・マージンで独立して包む。border-radius・border-image・box-shadow もフラグメントごとに個別適用され、`background-repeat: no-repeat` の背景画像もフラグメントごとに繰り返し描画される。

```css
.highlight {
  background: #ffe066;
  box-shadow: 0 0 0 4px #ffe066;
  padding: 0.2em 0.4em;
  box-decoration-break: clone;
  -webkit-box-decoration-break: clone;
}
```

**なぜ効果的か**: 複数行にまたがるインラインハイライト（マーカーで塗ったような表現）を、各行ごとにきれいに角丸・パディング付きで描画できる。`slice`（デフォルト）のままだと行の折り返し部分で装飾が破綻するが、`clone` を使えば各行が独立した「バッジ」のように整う。ブラウザサポートは Chrome 130+ と Firefox がインライン/ブロック双方向で対応、Safari は `-webkit-` プレフィックス付きでインラインのみ対応。

#### 4. `text-combine-upright` — 縦書き中の横並び数字・短い文字列

東アジアの縦書きタイポグラフィ向けのプロパティ。縦書き（`writing-mode: vertical-lr` など）の中で、短いテキスト（日付や数字など）を横向きの小さな文字列としてまとめて表示したい場合に使う。`writing-mode` が縦書きに設定されている場合にのみ効果を持つ。

```css
p {
  writing-mode: vertical-lr;
}

p span {
  text-combine-upright: all;
}
```

**なぜ効果的か**: 縦書き本文中に出てくる西暦や算用数字を、1文字ずつ縦に並べず横向きにまとめて読みやすくできる。日本語・中国語などのレイアウトで頻出する要求を、画像や特殊なマークアップなしで CSS だけで解決できる。

#### 5. `align-content` — Flexbox/Grid を使わないテキストの垂直中央揃え

従来「テキストを箱の中で垂直方向に中央揃えする」機能は `vertical-align` が担っていると誤解されがちだが、実際には比較的新しい `align-content` プロパティがブロックボックスに対してこれを行える、というのが記事の指摘。Flexbox や Grid のコンテナを作らなくても、通常のブロック要素に直接 `align-content` を指定するだけでコンテンツを縦方向に揃えられる。

```css
.box {
  height: 200px;
  align-content: center;
  text-align: center;
}
```

**なぜ効果的か**: これまで垂直中央揃えのためだけに `display: flex` や `display: grid` を追加し、余分なラッパーやレイアウトの副作用を発生させていたのに対し、`align-content` を通常のブロックに直接適用することでレイアウトへの影響を最小限に抑えつつ中央揃えができる。
