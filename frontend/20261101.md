## 1. HTML-in-Canvas API(Chrome 157 で安定版)
- **目的・問題意識**: DOM の対話性・アクセシビリティと、canvas のピクセル単位の高性能描画の間のギャップを埋める。実際の「生きた」HTML を 2D / WebGL / WebGPU の canvas に描画できる。
- **技術詳細(検索結果で確認できた範囲)**:
  - origin trial を経て Chrome 157(2026-10-26 の Chrome ブログ)で正式安定版。
  - canvas のセットアップは 2D / WebGL / WebGPU で共通。描画ステップはコンテキストごとに異なる。
  - 3D(WebGL/WebGPU)では要素の位置を、自分で計算した変換行列として `canvas.updateElementGeometry()` に渡す。ブラウザはその要素の CSS 解析・スタイル再計算を行わない。
  - API 名の変更(Chrome 155): WebGPU `copyElementImageToTexture` → `drawElementImageToTexture`、WebGL `texElementImage2D` → `texElementSubImage2D`。
  - ライブラリ: Three.js(実験的 `THREE.HTMLTexture`)、Pixi.js(HTML source)、CanvasUI。
  - フォールバック: 機能検出し、非対応なら別UI・浮動HTMLオーバーレイ・html2canvas / dom-to-image を使う。
- **効果的な理由**: 実DOMをそのまま描くため、アクセシビリティや入力処理を保ったまま canvas/3D 表現にHTMLを統合できる。
- **未取得**: 完全なコード例、デモの視覚的内容。
