## Issue #763: Ten CSS features worth voting for

### 概要

ブラウザベンダー合同の相互運用性プロジェクト **Interop 2027** で、開発者が提案をランキング投票できるようになった。複数の著名な書き手が自分の推し機能を公開しており、それらを紹介する号。

### 1. Interop 2027 ランキングツール（Firefox チーム / Jake Archibald）

- URL: https://interop-rank.jakearchibald.com/
- ①目的・問題意識: Interop 2027 でブラウザ間で実装を揃えるべき機能を、開発者の声で優先順位づけする。昨年は 1900 件超のランキングが集まり、Firefox の機能優先度付けに使われた。
- ②技術詳細: 好意的に評価する提案だけを順位づけする（ランク付けした項目はポジティブシグナルと見なされる）。**約10件ランク付けすれば十分**有用な入力になる、とのこと。Firefox チームは集計結果を公開しない可能性がある旨も明記。
- ③効果: ネガティブ票ではなくポジティブ票のみを集める設計で、実装優先度の判断材料になる。
- コード: なし（投票 UI）。Interop 2027 の focus area 発表予定は 2027-02-04（検索結果より）。

### 2. Josh Comeau「The Future of CSS ✨: My top 10 picks for Interop 2027」

- URL: https://www.joshwcomeau.com/css/interop-2027/
- ①目的: 実装が揃えば実務で効く CSS 機能10件を、ライブデモ付きで紹介し投票を促す。
- ②確認できた項目（順位は未確認）:
  - **CSS functions（`@function`）**: グラデーションや複雑な `calc` をカスタム関数として再利用できる。`inherit()` 関数も提案段階で、Interop 2027 に間に合うかは不明。
  - **`corner-shape`**: 角丸の形状（スクワークル等）を指定。border / outline / box-shadow にも追従する。
  - **Anchored container queries**: 詳細は未取得。
  - **Scroll-triggered animations**: 特定のスクロール位置でキーフレームアニメーションを開始する。CSS だけで扱えるようにする提案。
  - **`interpolate-size` / `calc-size()`**: `height: auto` などキーワードサイズのアニメーション。
  - **`reading-flow` / `reading-order`**: 視覚順とフォーカス順の不一致を解消する。
- ③効果: 現状は JS や回避策が必要な処理を CSS で宣言的に書けるようになる。
- コード・デモ内容: **未取得**（原文参照）。

### 3. Sara Soueidan「My top picks for Interop 2027」

- URL: https://www.sarasoueidan.com/blog/interop-2027-rankings/（2026-10-11 公開）
- ①目的: アクセシビリティ観点で、開発者の手作業を減らせる提案を優先して投票する。
- ②確認できた順位: 1. HTML `focusgroup` 属性 / 2. `ariaNotify()` API / 3. 見出しの `headingoffset` / `headingreset` 属性と `:heading()` 疑似クラス / 4-6. Interest Invokers、CSS `border-shape`、`interpolate-size` と `calc-size()`（4〜6 の順序は未確認）。
  - `focusgroup`: 子孫要素を1つのタブストップにまとめ、矢印キーで移動できるようにする（roving tabindex の JS が不要になる）。
  - `ariaNotify()`: ページからスクリーンリーダー等に任意のメッセージを読み上げさせる API（従来は live region の DOM 操作が必要）。
- コード: 未取得。

### Lea Verou「The best way to use icons in Web UIs」

- URL: https://lea.verou.me/blog/2026/icons/
- ①目的・問題意識: HTML を触らずに、CSS だけでアイコンの挿入・調整を行えるようにする。インライン SVG やアイコンフォントは、アイコン選択がマークアップに埋め込まれて保守しにくい。
- ②確認できた技術要点（コードは未取得）:
  - アイコンを `--icon-[name]` というカスタムプロパティに `<image>` 値（埋め込み data URI またはリモート URL）として保存し、デザイントークンとして扱う。
  - `::before` / `::after` の疑似要素に `mask` で適用する。マスクを使うため **アイコンは単色が前提**（透明度の変化は可）。
  - `@property` で非継承のカスタムプロパティを定義し、`@container` の **style query** でスコープを限定して、アイコンを状況に応じて切り替える。
  - `details::marker`、`select::picker-icon`、`option::checkmark` など疑似要素のアイコンもスタイルできる。
  - Safari(WebKit) には、マスクとカスタムプロパティ構成で container style query が初回描画時に正しく解決されないバグがある。回避策は、疑似要素への 0 秒アニメーションを WebKit 限定の `@supports` で付けること。
  - 実装パッケージ: `@nudeui/icons`（https://github.com/nudeui/icons）。
  - 関連仕様として CSS Linked Parameters に言及（Firefox が先行版を出荷、Interop 2027 の有力提案）。
- ③効果: アイコンの選択が CSS 側に集約され、テーマや状態に応じた切り替えが HTML 変更なしでできる。
- 完全なコードとデモ: **未取得**（原文参照）。

### Darius Cepulis (Video.js)「What the iPhone Duo means for web development (and Video.js)」

- URL: https://videojs.org/blog/iphone-duo-web-development
- 内容: iPhone Duo シミュレータで **Device Posture API**（`navigator.devicePosture`、CSS `@media (device-posture: folded)`）と **Viewport Segments API** を検証。いずれも Safari 27.1 beta でフラグ配下。Netflix の折りたたみ時プレイヤー UI を Video.js で再現しようとした。Apple の全画面制限が課題。
